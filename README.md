# Website A11y Checker

## Features

- Accessibility scanning using axe-core
- Chrome Extension (Manifest V3)
- Displays:
  - Violations
  - Passes
  - Incomplete
  - Inapplicable
- Shows Top 3 Accessibility Issues

## Tech Stack

- HTML
- CSS
- JavaScript
- Chrome Extension API
- axe-core
